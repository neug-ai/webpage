# 表达式

表达式是 Cypher 的基本组件，允许您在查询中计算值、执行计算和操作数据。与专注于关系数据操作的传统 SQL 不同，Cypher 表达式专为图数据结构设计，提供遍历边、模式匹配和图特定计算的强大功能。

Cypher 表达式具有以下主要用途：

- **值计算**：从节点属性、边属性或计算结果计算派生值
- **条件评估**：创建布尔表达式以过滤节点、边或路径
- **数据转换**：转换和格式化数据类型以用于显示或进一步处理
- **图遍历**：使用路径表达式和模式匹配导航图结构
- **聚合**：对节点或边集合执行计算
- **字符串和文本处理**：操作文本数据以进行搜索、显示或分析

Cypher 表达式由两大类组件构成：

1. **运算符**：对操作数执行基本操作的符号和关键字
2. **函数**：封装复杂逻辑并接受参数的预定义操作

这些组件协同工作，创建强大的表达式，可处理简单计算和复杂图操作。

## 运算符

NeuG 中的运算符是对操作数执行操作的符号或关键字。它们是构建表达式和查询的基本单元。

### 支持的运算符类型

| 类型 | 描述 |
|------|-------------|
| [比较运算符](comparison_op) | 用于比较值的运算符（如 `=`、`<>`、`<`、`>`、`<=`、`>=`) |
| [逻辑运算符](logical_op) | 用于组合条件的布尔运算符（如 `AND`、`OR`、`NOT`) |
| [算术运算符](arithmetic_op) | 数学运算（如 `+`、`-`、`*`、`/`、`%`) |
| [空值运算符](null_op) | 处理空值的操作（如 `IS NULL`、`IS NOT NULL`) |
| [列表运算符](list_op) | 处理列表数据结构的操作（如 `IN`) |

## 函数

NeuG 中的函数是接受输入参数并返回计算值的预定义操作。它们提供数据操作和分析的专用功能。

### 支持的函数类别

| 类别 | 描述 |
|----------|-------------|
| [聚合](agg_func) | 对值集合进行操作并返回单个结果的函数（例如 `COUNT`、`SUM`、`AVG`、`MAX`、`MIN`） |
| [类型转换](cast_func) | 用于在不同格式之间转换数据类型的函数 |
| [列表](list_func) | 用于追加和连接类列表值的函数 |
| [时间](temporal_func) | 用于处理日期和时间数据的函数 |
| [图模式](graph_func) | 专为节点、边或路径设计的函数 |
