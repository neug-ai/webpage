# LIMIT 子句

LIMIT 用于控制输出结果的数量。除了单独使用外，还可以与 ORDER BY 组合用于 TopK 操作。NeuG 目前支持 LIMIT 中使用两种类型的表达式：1. 单个整数常量。2. 仅包含常量参数的算术表达式。

## 使用整数值的 LIMIT

```
MATCH (a:Person)
RETURN a.age
LIMIT 2;
```
由于输出未进行排序，结果可能是任意两条记录。

输出：
```
+------------+
|   _0_a.age |
+============+
|         29 |
+------------+
|         27 |
+------------+
```

## 使用整数表达式的 LIMIT

```
MATCH (a:Person)
RETURN a.age
LIMIT 1+1;
```

输出：
```
+------------+
|   _0_a.age |
+============+
|         29 |
+------------+
|         27 |
+------------+
```

# SKIP 子句

LIMIT 控制输出结果的数量，相当于确定输出结果行号范围为 [0, upper_bound)。SKIP 控制跳过输出结果的前几行，相当于确定输出结果行号范围为 [lower_bound, +∞)，这里我们假设行号从 0 开始。

## 使用整数值跳过

```
MATCH (a:Person)
RETURN a.age
SKIP 2;
```
该查询用于跳过前两行结果。

输出：
```
+------------+
|   _0_a.age |
+============+
|         32 |
+------------+
|         35 |
+------------+
```

## 使用整数表达式的 SKIP

```
MATCH (a:Person)
RETURN a.age
SKIP 1+1;
```

输出：
```
+------------+
|   _0_a.age |
+============+
|         32 |
+------------+
|         35 |
+------------+
```
