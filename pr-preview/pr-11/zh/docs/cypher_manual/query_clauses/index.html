查询子句

在本章中，我们主要介绍 NeuG 查询相关的子句操作。下表总结了这些操作的类型和一般用途：

子句描述
MATCH查找图模式
WHERE基于属性进行过滤
WITH基于属性进行投影或聚合
RETURN输出投影或聚合结果
ORDER进一步排序中间结果或输出结果
SKIP跳过结果的顶部部分，确定输出结果的下界
LIMIT截断结果，确定输出结果的上界
MERGE确保模式存在；匹配或创建
UNION合并具有相同模式的多个分支结果

我们将使用 modern 图  作为示例来介绍每个子句的具体作用。
