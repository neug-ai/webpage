快速开始

从安装到第一次查询

NeuG 与你的应用运行在一起。安装依赖、打开数据库，然后直接使用 Cypher 查询。

quickstart.py
$ pip install neug

import neug

db = neug.Database("")
conn = db.connect()

result = conn.execute("""
  MATCH (n) RETURN n LIMIT 10
""")
